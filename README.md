# ⛪ France catholique

Application Streamlit pour apprendre la foi catholique à travers l'histoire, les saints et les lieux de France.

## Rubriques

- **Accueil** : temps liturgique du jour, saint de France à l'honneur, chapelet du jour, patrons de la France
- **Calendrier liturgique** : date de Pâques et fêtes mobiles pour n'importe quelle année, fêtes fixes, couleurs liturgiques
- **Saints de France** : 34 saints avec leur fête, leur époque et leur histoire (recherche et filtre par région)
- **Sanctuaires et pèlerinages** : carte de 30 lieux saints, chemins de Compostelle, grands pèlerinages
- **Histoire** : chronologie de l'Église en France, des martyrs de Lyon (177) à la réouverture de Notre-Dame (2024)
- **Apparitions mariales** : rue du Bac, La Salette, Lourdes, Pontmain, Pellevoisin, Le Laus, Cotignac
- **Ordres et docteurs** : ordres religieux nés en France et docteurs de l'Église français
- **Prières et chapelet** : Notre Père, Je vous salue Marie, Credo, Angélus, Souvenez-vous… et les mystères du Rosaire
- **Traditions et lexique** : Chandeleur, Fête-Dieu, 15 août, Fête des Lumières, crèche provençale…
- **Quiz** : 10 questions tirées au hasard parmi 20

## Lancer l'application

```
$ pip install -r requirements.txt
$ streamlit run streamlit_app.py
```

## Tests

```
$ pip install pytest
$ python -m pytest
```
